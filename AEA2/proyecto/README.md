# Punt de Joc · Aplicación de laboratorio DAW2
Cada carpeta es una etapa independiente. No hay que instalar todos los servicios al empezar.

| Etapa | Objetivo |
|---|---|
| 01-estatic | Recursos estáticos y publicación con Apache |
| 02-php | Generación de HTML en el servidor |
| 03-bdd | Conexión, persistencia y clasificación |
| 04-java | Despliegue de un WAR cerrado |
| 05-contenidors | Entorno reproducible con Compose |

Victoria 3 puntos, empate 1, derrota 0. Las partidas pendientes no cuentan. Los empates comparten posición (1,2,2,4). Las rondas están preparadas; no hay emparejamientos automáticos.

Personalizad textos y CSS. Mantened los nombres internos de tablas y campos, que son el contrato entre SQL y aplicación. El español es el idioma principal de los materiales; los identificadores internos conservan sus nombres originales.

Repositorio compartido por equipo y despliegue individual. No subáis secretos ni datos personales reales. Consultad el README de cada etapa antes de arrancarla.
