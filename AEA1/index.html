AEA1 · RA6 · 10 hores

Documentació,
Git i GitHub

La primera AEA posa les bases del treball professional que aplicarem durant tot el mòdul: documentar, versionar, compartir i comprovar els canvis d'una aplicació.

5 sessions · 10 hores · treball principalment individual

Per què comencem aquí?

Abans de desplegar, cal saber explicar i controlar el projecte

Una aplicació web no és només el seu codi. També necessita documentació perquè altres persones la puguin entendre, un historial per saber què ha canviat i eines que ajudin a comprovar que el projecte continua funcionant. Aquest bloc introdueix aquests hàbits abans de treballar amb servidors i desplegaments.

Documentar

Crearem documentació tècnica amb Markdown, README i comentaris Javadoc, MK per explicar el projecte i el codi.

Controlar canvis

Utilitzarem Git i GitHub per crear repositoris, registrar commits, treballar amb branques i compartir el treball.

Comprovar

Publicarem documentació i entendrem com una integració contínua verifica automàticament els canvis.

Al final de l'AEA

Què hauries de poder fer?

Gestionar el teu repositori

Crear-lo, revisar l'estat, preparar canvis, fer commits descriptius, sincronitzar-lo amb GitHub i participar en una Pull Request.

Deixar evidències clares

Presentar un README útil, documentació de codi, un historial coherent, una web publicada i una comprovació automàtica interpretable.

L'avaluació combina les pràctiques de documentar el codi i GitHub amb un qüestionari final. Es valoren tant el resultat com el procés i la capacitat d'explicar les eines utilitzades.

Abans d'entregar

  • README amb descripció, estructura, instruccions i enllaç a la web publicada.

  • Sense contrasenyes ni dades sensibles; amb .gitignore.
  • Una branca integrada, una Pull Request revisada, GitHub Pages i Actions funcionant.

Introducció

Bones pràctiques de programació

El codi també comunica. Noms significatius, una estructura ordenada i comentaris útils permeten que l'equip pugui entendre, modificar i mantenir el projecte.

Noms significatius

preuFinal explica més que x. Cada nom ha d'ajudar a entendre la finalitat de la variable, funció o classe.

Comentaris que aporten context

No repeteixen el codi: expliquen el perquè d'una decisió, una limitació o un comportament no evident.
