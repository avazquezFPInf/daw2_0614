GitHub Pages y GitHub Actions

Publica una web desde el repositorio e identifica las comprobaciones automáticas que se ejecutan con cada cambio.

GitHub Pages

Publica la web desde main, compruébala en una ventana privada y añade el enlace al README.

GitHub Actions

Identifica el workflow, cuándo se ejecuta y el resultado de la comprobación después de cada push o Pull Request.

Cierre
