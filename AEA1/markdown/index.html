Markdown

Guia bàsica per crear documentació tècnica clara, portable i preparada per treballar amb Git.

Descarrega la guia en Markdown ↓

Què és Markdown?

És un llenguatge de marcat lleuger que dona format al text de manera senzilla. És habitual en documentació tècnica, fitxers README, incidències i apunts de projecte. Aquesta pàgina és una guia de referència: no cal memoritzar tota la sintaxi.

1. Encapsalaments

Els encapsalaments estructuren el document. La quantitat de # defineix el nivell; deixa un espai entre el símbol i el text.

# Encapsalament 1
## Encapsalament 2
### Encapsalament 3

Normalment utilitzem un únic títol de nivell 1 i organitzem la resta del document amb nivells inferiors.

Activitat pràctica

4. Crea perfil.md

És la teva carta de presentació en Markdown. Utilitza un to adequat per compartir-la amb companys i professorat; no hi incloguis dades personals sensibles.

  1. Afegeix un títol principal, dos subtítols i una presentació amb negreta i cursiva.
  2. Inclou tecnologies que coneixes, tres pel·lícules i tres cantants o grups.
  3. Afegeix un enllaç d'interès, una imatge opcional i una taula amb tecnologies que vulguis aprendre.
  4. Inclou un bloc de codi, una cita, un objectiu del curs i una checklist amb elements assolits i pendents.
  5. Previsualitza el document a Visual Studio Code abans de lliurar-lo.
