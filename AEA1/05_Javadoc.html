Javadoc

Genera documentació HTML a partir dels comentaris del codi Java.

/**
 * Calcula el preu final.
 * @param preu preu inicial
 * @return preu final
 */

Descriu què fa l'element, les dades que rep i què retorna; no comentis línia per línia.

javadoc -d docs src/*.javaObre docs/index.html
