2 · GitHub i remots · WIP

GitHub

Llevamos el historial local de Git a un espacio web para conservarlo, consultarlo y compartirlo.

0 · Contextualización

Git es local; GitHub es el espacio compartido

GitHub és una plataforma web que allotja repositoris Git. Va aparèixer el 2008, després d'altres plataformes de control de versions, i es va popularitzar perquè fa visible la història del projecte i facilita la col·laboració des del navegador.

Git

És l'eina que crea commits i manté l'historial al teu ordinador, fins i tot sense connexió.

GitHub

És un repositori remot: rep una còpia de l'historial i afegeix interfície web, permisos, Pull Requests, Pages i Actions.

Objectiu d'avui

Publicar de forma segura el teu repositori local perquè el professorat en pugui revisar el procés.

1 · Cuenta personal

Date de alta i cuida la identitat digital

  1. Crea un compte a GitHub amb un correu que puguis consultar.
  2. Tria un nom d'usuari adequat i reconeixible; el necessitaràs per compartir el repositori.
  3. Verifica el correu electrònic i activa l'autenticació de dos factors si tens l'opció disponible.
  4. Revisa el perfil: no cal publicar dades personals innecessàries.

2 · Repositorio remoto

Crea el espacio del proyecto

Des de la pàgina principal de GitHub, selecciona New repository i crea un repositori anomenat DAW2_M08_NombreApellido. Per exemple: DAW2_M08_MariaGarcia.

Visibilitat

Per a esta primera entrega, puede ser público si no contiene datos sensibles. Si se prefiere privado, se podrá compartir después mediante una invitación o el mecanismo que indique el profesorado.

Importante

No marques «Add a README», «Add .gitignore» ni licencia: ya existe un repositorio local y queremos publicar su historial sin conflictos.

Copia la URL HTTPS que GitHub muestra al crear el repositorio.

3 · Primer push

Conecta Git local con GitHub

Abre la terminal dentro de la carpeta que ya contiene perfil.md, chuleta-git.md y su historial de commits.

git remote add origin URL_DEL_REPOSITORIO
# Conecta el repositorio local con la URL HTTPS de GitHub.

git remote -v
# Comprueba que origin apunta a la dirección correcta.

git branch -M main
# Asegura que la rama principal se llama main.

git push -u origin main
# Envía todos los commits locales a GitHub y configura el seguimiento remoto.

GitHub puede abrir el navegador para iniciar sesión. Si pide una contraseña en la terminal, no uses la contraseña de la cuenta: completa la autenticación en el navegador o sigue la indicación de GitHub.

4 · Comprueba el resultado

La historia también se ve en la web

  1. Actualiza la página del repositorio en GitHub.
  2. Comprueba que aparecen perfil.md y chuleta-git.md.
  3. Abre la lista de commits y compara los mensajes con git log --oneline.
  4. Abre perfil.md: GitHub lo renderiza automáticamente como documento Markdown.
  5. Revisa que no hayas publicado contraseñas, tokens, direcciones ni otros datos personales sensibles.

5 · Entrega inicial

Comparte el enlace por Moodle

Para esta primera práctica, entrega en Moodle la URL completa de tu repositorio de GitHub. Es la opción más simple: el profesorado puede consultar los archivos y la historia de commits, y tú mantienes la propiedad del proyecto.

Antes de entregar

  • El enlace abre tu repositorio correcto.
  • Se ven perfil.md, chuleta-git.md y sus commits.
  • El nombre del repositorio sigue el formato acordado.
  • No contiene información sensible.
